Run your own case

The demo plays a saved example. To write your own case, connect a Gloo key. The safety checks run the same way either way.

  1. Get a Gloo AI Studio key at platform.ai.gloo.com.
  2. Put it in the .env file at the root of the repo as GLOO_API_KEY=your-key. Never commit it.
  3. Restart the app: run python3 -m app.server from the code/ folder.

Optional

  • JEV_API_KEY turns on the Jev check. Without it, the Jev check is skipped. The rest of the pipeline still runs, and our own named checks still run on every draft.
  • YVP_APP_KEY adds YouVersion verses. Without it, Nury uses the verified public-domain bank.
